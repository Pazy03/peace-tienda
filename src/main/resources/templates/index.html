Bienvenida a TechShop

Este proyecto corresponde al curso de Desarrollo de Aplicaciones Web y Patrones. Aquí se trabaja con Spring Boot, MVC, Thymeleaf, Bootstrap, MySQL, JPA/Hibernate y Spring Security.

El sistema permite gestionar categorías y productos, así como realizar consultas por rango de precios y probar seguridad con roles de usuario.
